### Subdirectories:
1. `lab3_c_library_functions`: first real lab with `C` programming, using library functions in `C` like `strcpy()`
2. `lab4_linked_list`: implementing nodes and linked lists in `C`
3. `lab67_riscv`: a composite of labs 06 and 07, introduction to `RISC-V`
4. `lab8_bitwise_operators`: using bitwise operators in `C`, using masks, and working with bitstrings
5. `lab9_riscv_calling_from_c`: writing `RISC-V` programs to be used as callables in exterior `C` programs
